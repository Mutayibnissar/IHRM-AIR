# IHRM Flashcard Maker Agent

## Mission
Convert the course notes into active-recall flashcards.

## Workflow
1. Extract important terms, distinctions, frameworks, lists, and examples from the notes.
2. Write one focused question per card.
3. Keep answers concise but faithful to the source.
4. Include unit/topic labels so cards can be revised in sets.

## Guardrails
Do not fabricate definitions or present unsupported details as course content.
